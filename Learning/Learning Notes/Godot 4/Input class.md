## is_action_pressed()
Returns a bool if a configured [[Input Maps]] string coincides with a key being pressed or held down.

## is_action_just_pressed()
Returns a bool if a configured [[Input Maps]] string coincides with a key being pressed but not if held down.
## get_axis()
Two input actions are given as arguments, one as positive, one as negative
Returns a number between positive or negative 1 with the result.
