When a CollisionPolygon2D Node is selected new tools will appear in the 2D explorer of the editor:
![[Pasted image 20230904025900.png]]

The create point tool lets you create new points using the 2D editor:
![[Pasted image 20230904030022.png]]

The edit point button can be use to change a point position:
![[Pasted image 20230904030211.png]]

Creating a new point will erase the current polygon.
The delete point tool can be use to erase polygon points.

By right clicking the Polygon Property you can copy the polygon coordinates to use with other nodes, like Polygon2D:
![[Pasted image 20230904031349.png]]
