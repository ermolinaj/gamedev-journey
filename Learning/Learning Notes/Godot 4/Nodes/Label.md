A simple node that displays text.

## Label Settings
Inside it´s properties you can create a new LabelSettings.
Inside the new LabelSettings you can modify its properties.
![[Pasted image 20230904195830.png]]
If you modify a property of this LabelSetting it will affect every label that uses this settings.

You can solve this bu right clicking it and selecting the "Make Unique" option.
